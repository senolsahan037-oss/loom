# Loom Project Structure

Loom root contains first-class tools only.

Root tools:
- ArrangementGPS: song structure and arrangement planning
- Sensei: generator family
- AIMixMaster: mix and master analysis/planning
- Presetor: Ableton preset and device-chain intelligence
- AISoundDesigner: sound design and texture planning
- Renderer: render, stem, and package export layer
- Producer: orchestration, memory, roadmap, and tool routing
- AbletonScripts: Ableton integration scripts
- Agents: shared agent definitions
- Docs: documentation
- Sessions: development session logs

Rule:
Do not create random root folders. New folders must belong inside one of the tools unless they represent a new first-class Loom tool.
